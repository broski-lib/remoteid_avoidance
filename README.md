# remoteid_avoidance

The library lives in `remoteid_avoidance/`. The separate `main.py` runs the CLI
from this repository. Installing the library does not install the CLI.

## Use the library

```sh
uv sync
uv run python -c 'import remoteid_avoidance'
```

## Run the command

```sh
uv run python main.py
```

## Build the package

```sh
uv build
```

This builds only the library.
